# Guess the Era photos

Add Stephanie photos to this folder. Start every image filename with her age when it was taken:

- `0-newborn.jpg`
- `7-first-day-of-school.png`
- `18-graduation.webp`
- `30-birthday.jpeg`

Ages must be whole numbers from 0 through 30. Supported formats are AVIF, GIF, JPG/JPEG, PNG, and WebP.

The age in the filename is read only by the server and is not sent to players until the host reveals the answer. Restart the server after adding, removing, or renaming photos.
